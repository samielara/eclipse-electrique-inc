Intégration Directe dans Canva

Ces fichiers sont prêts à être glissés-déposés directement dans Canva pour concevoir vos maquettes, présentations clients ou visuels publicitaires :

  1. Ouvrez votre projet sur Canva.com.
  2. Glissez-déposez n'importe quel fichier depuis public/media/ vers la barre latérale Importations de Canva.
  3. Toutes les images respectent le ratio d'aspect idéal pour les cartes (4:3) et les bannières grand écran (16:9).
